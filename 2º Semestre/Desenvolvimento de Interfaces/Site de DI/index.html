HTML WCAG Heurísticas de Nielsen Tags Semânticas


O Que é HTML?

HTML (Hyper Text Markup Language) é a linguagem usada para criar a estruturar paginas da web.
Ele não é considerado uma linguagem de programação e sim uma linguagem de marcação.

Como Funciona o HTML?

Ele é formado por TAGS que são utilizadas para organizar o conteúdo.
As tags dizem ao navegador o que deve ser exibido e ele faz a leitura e mostra as informações, como por exemplo:

  • <h1>   → Título Grande
  • <h2>   → Subtítulo
  • <h3>   → Subtítulo Menor
  • <p>    → Parágrafo
  • <a>    → Link
  • <br>    → Quebra uma Linha

Exemplo de Código

 <h1>Este é um Título</h1>
  <p>Este é um parágrafo</p>

Exemplo de <code>

Use a tag <code> para marcar trechos de código em linha:

<code>console.log('Olá mundo');</code>

Por que HTML é importante?

O HTML é a base de todos os sites. Sem ele, não existiria estrutura na web.
Ele trabalha junto com CSS (visual) e JavaScript (interatividade).

Estrutura Básica de um Documento HTML

O HTML é organizado em uma estrutura hierárquica, abaixo está o esqueleto padrão do HTML5:

<!DOCTYPE html>
<html lang="pt-BR">
  <head>
    <meta charset="UTF-8">
    <title>Título da Página</title>
  </head>
  <body>
    <h1>Conteúdo Principal</h1>
    <p>Texto aqui.</p>
  </body>
</html>

Cada tag tem um papel, como por exemplo:

<head> contém metadados (informações sobre a página)
<body> tem o conteúdo visível da página.
<title> é o título da página na aba do navegador.
<h1> é o título principal da página.
<p> é um parágrafo de texto.

Elementos e Atributos

Um elemento HTML é composto por tags. Um atributo fornece informações extras.

<a href="https://exemplo.com" target="_blank">Clique aqui</a>
<img src="imagem.png" alt="Descrição da imagem">

href, target, src, alt são atributos.

Elementos Inline vs Block

Block: ocupam toda a largura disponível (ex: <p>, <div>, <h1>)

Inline: ocupam apenas o espaço necessário (ex: <span>, <a>, <code>)

<!-- Block -->
<div>Este div ocupa toda a linha</div>

<!-- Inline -->
<span>Este span</span> fica inline com o texto.

Tags Mais Comuns

Estrutura

  • <header> — Cabeçalho
  • <main> — Conteúdo principal
  • <footer> — Rodapé
  • <section> — Seção temática

Texto

  • <h1> a <h6> — Títulos
  • <p> — Parágrafo
  • <em> — Ênfase
  • <strong> — Forte/Bold

Mídia

  • <img> — Imagem
  • <audio> — Áudio
  • <video> — Vídeo
  • <iframe> — Conteúdo externo

Boas Práticas ao Escrever HTML

  • ✓ Use tags semânticas quando possível
  • ✓ Indente seu código para melhor legibilidade
  • ✓ Sempre feche as tags corretamente
  • ✓ Use atributos alt em imagens (acessibilidade)
  • ✓ Mantenha HTML separado de CSS e JavaScript
  • ✗ Não use <br> apenas para espaçamento (use CSS)
  • ✗ Não use onclick inline (use JavaScript externo)
