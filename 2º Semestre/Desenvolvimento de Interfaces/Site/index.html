O Que é HTML?

HTML (Hyper Text Markup Language) é a linguagem usada para criar a estruturar paginas da web.
Ele não é considerado uma linguagem de programação e sim uma linguagem de marcação.

Como Funciona o HTML?

Ele é formado por TAGS para organizar o conteúdo.
As tags dizem ao navegador o que deve ser exibido e ele faz a leitura e mostra as informações.

  • <h1>   → Título Grande
  • <h2>   → Subtítulo
  • <h3>   → Subtítulo Menor
  • <p>    → Parágrafo
  • <a>    → Link
  • <br>    → Quebra uma Linha

Exemplo de Código


            <h1>Este é um Título</h1>
            <p>Este é um parágrafo</p>
